# Daniel Obanda Mabinda — Unified Portfolio

A responsive static portfolio combining ICT, web systems, AI automation, graphic design and digital-service work into one site.

## Files
- `index.html` — site content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation, filtering and reveal interactions
- `vercel.json` — Vercel-ready static hosting settings

## Deploy to Vercel
1. Put these files in a GitHub repository, or upload/import the folder into Vercel.
2. Choose **Other** / static project if prompted for a framework.
3. No build command is required.
4. The site root is the project root.
